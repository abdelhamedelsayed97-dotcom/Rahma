المقدمة

تعتبر CSS هي اللغة المسؤولة عن تنسيق وشكل صفحات الويب. بينما HTML تبني الهيكل، تأتي CSS لتضيف الألوان والخطوط والتصميم. تم تطويرها لتسهيل فصل المحتوى عن التصميم.

عرض الموضوع

تستخدم CSS للتحكم في مظهر العناصر في صفحة HTML. يمكننا تغيير لون الخلفية وحجم الخط ومكان العنصر.

أنواع CSS

يوجد ثلاث طرق لكتابة CSS داخل الصفحة:

النوع الاستخدام
Inline CSS يكتب داخل الوسم نفسه
Internal CSS يكتب داخل وسم style في head
External CSS يكتب في ملف خارجي ويربط بالصفحة
